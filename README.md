# SlopeShield – Smart Landslide Monitoring and Early Warning System

SlopeShield is a **multi-parameter IoT prototype** for slope condition monitoring, prototype risk assessment, early warning, and automated hazard-zone response.

> **Important scientific limitation**
>
> SlopeShield is a controlled educational innovation prototype. It is **not** a scientifically validated system for real-world landslide prediction.

## Project scope

The prototype demonstrates this concept pipeline:

**Detection → Analysis → Risk Classification → Early Warning → Automated Response**

Current status focuses on:
- ESP32-based local monitoring
- Multi-level status (SAFE / WARNING / DANGER)
- Dashboard foundation with DEMO and future LIVE architecture

## Current hardware status

Already tested/available:
- ESP32 DevKit
- HC-SR04 ultrasonic sensor
- Tilt switch
- 16x2 I2C LCD
- Blue, yellow, and red LEDs
- 1 kΩ and 220 Ω resistors
- 1000 µF capacitor

Planned next integrations:
- Soil moisture sensor
- Rain/water detection
- Buzzer
- Servo motor (prototype hazard-zone barrier)

### Current ESP32 pin configuration (active prototype)

- LCD SDA: GPIO 27
- LCD SCL: GPIO 26
- HC-SR04 TRIG: GPIO 14
- HC-SR04 ECHO: GPIO 33
- Blue LED: GPIO 32
- Yellow LED: GPIO 13
- Red LED: GPIO 25
- Tilt switch: GPIO 12 to GND (`INPUT_PULLUP` logic)

The dashboard app is in `dashboard/` and currently provides:
