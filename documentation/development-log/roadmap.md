# Development Roadmap

## Phase 1 (current foundation)
- Repository structure and core documentation
- Dashboard UI and DEMO mode data architecture
- Configurable prototype risk classification

## Phase 2 (integration)
- ESP32 telemetry transport for LIVE mode
- Firebase Authentication and Firestore integration via environment variables
- Event logging and historical data persistence

## Phase 3 (monitoring expansion)
- Live charts and event timeline views
- Soil moisture and rainfall physical sensor integration
- Buzzer and servo barrier event synchronization

## Phase 4 (operational hardening)
- Alert workflows and role-based dashboard access
- Calibration workflows for prototype model tuning
- Deployment automation for dashboard hosting
