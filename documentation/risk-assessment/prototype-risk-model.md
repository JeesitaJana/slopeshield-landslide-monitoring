# Prototype Risk Assessment Model

Risk classification currently uses configurable thresholds and rule combinations.

## Current labels
- SAFE
- WARNING
- DANGER

## Prototype logic intent
- WARNING when one or more instability indicators rise
- DANGER when multiple significant indicators are present together

Indicators currently represented in demo architecture:
- Displacement
- Tilt detection
- Soil moisture
- Rainfall/water exposure

This model is intended for controlled demonstration and educational use only.
