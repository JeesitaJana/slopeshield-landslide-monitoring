# Current ESP32 Pin Configuration

These assignments match the currently assembled and tested prototype.

## LCD
- SDA → GPIO 27
- SCL → GPIO 26

## HC-SR04
- TRIG → GPIO 14
- ECHO → GPIO 33

## LEDs
- Blue → GPIO 32
- Yellow → GPIO 13
- Red → GPIO 25

## Tilt switch
- One terminal → GPIO 12
- Other terminal → GND
- Logic mode: `INPUT_PULLUP`
